1. "Smart HS Code Matcher" (Zero-Friction Semantic Input)
The Problem: Most MSME owners do not know their Harmonized System (HS) codes, which are strictly required for international shipping. Traditional government customs portals use basic keyword searches, meaning if an MSME types "Wooden desk" but the legal database calls it "Furniture, wooden, of a kind used in offices," the search returns zero results, blocking the user from exporting.
The Upgrade: Implement an AI-powered, auto-completing search bar that understands intent and context, rather than just exact words.
As the user types their everyday product description (e.g., "Handwoven Rattan Chair"), the AI instantly translates this into the official customs terminology.
A dropdown appears suggesting the top 3 most accurate 6-digit HS codes, accompanied by a plain-English explanation generated by the AI on why this code fits, giving the MSME total confidence to click and proceed.

How to Build It (The Technical Implementation)
Since you are already using Supabase, FastAPI, and FastMCP, this is actually highly efficient to build using vector embeddings.
1. The Database (Supabase pgvector)
You will pre-load a Supabase table with the official ASEAN HS Code directory.
You will generate an "embedding" (a mathematical representation of the text) for every HS code description using an embedding model (like text-embedding-004 from Google) and store it in a vector column.
2. The Backend Tool (FastAPI + FastMCP)
When the user types "Rattan chair" in your Next.js frontend, it hits your FastAPI backend.
You create a FastMCP tool called suggest_hs_codes.
This tool converts the user's query ("Rattan chair") into an embedding, and performs a similarity search against your Supabase pgvector database.
Even though the words don't match exactly, the math knows that "Rattan chair" is semantically identical to the official HS code 9403.89 ("Furniture of cane, osier, bamboo or similar materials").
3. The LLM Polish (Gemini)
Before sending the raw database results back to the frontend, you pass the top 3 matches to Gemini with a prompt: "Explain to a small business owner in one simple sentence why these HS codes match their search for 'Rattan chair'."
The Output to the User: * HS 9403.89 (Confidence: 98%) - AI Note: Select this if your chair is primarily made of woven bamboo, rattan, or cane.
